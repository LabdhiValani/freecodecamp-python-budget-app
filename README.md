# FreeCodeCamp Python Budget App

This project was developed as part of the freeCodeCamp Python Certification.

## Project Description

The Budget App allows users to create budget categories, deposit and withdraw money, transfer funds between categories, check available funds, and generate a spending chart.

## Features

- Create budget categories
- Deposit money
- Withdraw money
- Transfer money between categories
- Check account balance
- Generate spending chart

## Technologies Used

- Python
- Object-Oriented Programming
- Classes and Objects
- Lists and Dictionaries
